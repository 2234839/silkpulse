# 悬浮球交互

## 需求：悬浮球左右分区交互（选元素 / 拖动） [[floating-ball.split]]

背景：悬浮球当前「拖出球体即进入选元素」的逻辑有问题：
1. 拖动悬浮球到任意位置（仅想挪位置）都会触发选元素，行为不符合预期。
2. 选元素模式下悬浮球没有像光标一样跟随移动（例如挂在手指右下角跟随）。

方案：将悬浮球交互按左右两半分区：
- **左半部分**：光标样式区域。触摸该区域 → 悬浮球切入光标模式（球半透明并跟随指针移动，挂在指针右下角），指针下的元素实时高亮，松开选中并联动控制台 Element 面板（复用现有 inspectElement 链路）。
- **右半部分**：仅拖动悬浮球（位置持久化逻辑不变）；未拖动的单击仍复制接入 agent 提示词。

实现见 [floating-ball.ts](../packages/sdk/src/floating-ball.ts)

### 验收
- 在右半部分按住拖动：只移动悬浮球位置，不进入选元素、不高亮任何元素。
- 在左半部分按住：球变光标跟随指针移动，扫过的元素实时高亮，松开选中 → 控制台 Element 面板定位 + 复制描述。
- 左半区域有可见的光标样式（crosshair）与分区视觉提示。
