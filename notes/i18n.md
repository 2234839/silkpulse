# 多语言（进军英文世界）

## 需求：控制台 i18n 基础设施 + 双语消息包 [[i18n.infra]]

背景：产品要面向英文用户，控制台（apps/console）UI 文案目前全部硬编码中文。

方案：
- 引入 vue-i18n（composition 模式 + globalInjection），`en` 消息包为类型基准（`MessageSchema`），`zh` 包结构必须与之对齐，缺 key/多 key 编译期报错。
- 语言解析优先级：localStorage（silkpulse-locale）> 浏览器语言（zh 开头）> 英文；切换语言同步 <html lang> 与 <title>。
- 消息包按组件命名空间组织（auth / shell / common …）。
- 校验：`node scripts/i18n-check.mjs` 检查 en/zh key 一致性 + 模板残留硬编码中文（HTML 注释与 blog 文章正文除外），作为渐进迁移的 ratchet。

实现见 [i18n/index.ts](../apps/console/src/i18n/index.ts)、[messages/en.ts](../apps/console/src/i18n/messages/en.ts)、[messages/zh.ts](../apps/console/src/i18n/messages/zh.ts)、[i18n-check.mjs](../scripts/i18n-check.mjs)

### 验收
- en/zh 一键切换，刷新后语言保持；标题与 html lang 同步。
- vue-tsc 类型检查通过（zh 包 key 与 en 完全对齐）。
- headless 测试无回归（基线对照：失败集合与改动前一致，均为环境既有问题）。

## 需求：登录页（AuthPage）与控制台外壳（ConsoleApp）双语化 [[i18n.auth-shell]]

AuthPage 全部 UI 文案（定位描述、能力卡片、登录表单、游客建 Key 流程、错误提示）与 ConsoleApp 顶栏/空状态/首进密钥弹窗迁入消息包；两处均加语言切换入口（AuthPage 右上角下拉，控制台顶栏按钮）。游客随机项目名词库按语言区分（组件内 locale 键控，词库行尾 i18n-allowed 标记豁免扫描）。

实现见 [AuthPage.vue](../apps/console/src/components/AuthPage.vue)、[ConsoleApp.vue](../apps/console/src/ConsoleApp.vue)
